# Cook's membrane: accuracy gain vs generations trained

Metric: gain = automesher error / agent error (`checks.gain`), ignoring DOFs. Generation 0: best 1.25x, mean 1.10x; generation 10: best 4.83x, mean 4.68x (title: the mean). Circled: the two runs drawn in the panels at their own gain (the generation-10 run shown, `g10-cooks_membrane-a7`, is the best by score, gain 4.76x; the best gain, 4.83x, is another run). Agents use ~2x the automesher's DOFs by the end (median 716 vs 336), so this overstates per-DOF efficiency; fig_B1 is the fair version. Only correctly set-up runs are used (44 of 44): a run counts when its recorded setup, re-solved on its own mesh, gives the same field error (to 1e-6) as the problem's own setup (`ace/checks.py reference_setup`), so the differences shown are the mesh alone (`data/runs_deep1.csv`, column setup_ok). Values: `data/per_generation_cooks_membrane.csv`.
