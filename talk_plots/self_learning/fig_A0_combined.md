# Cook's membrane: four solutions on one colour scale

Left to right: gmsh automesher (336 DOFs, field error 5.11 %); best generation-0 agent `g0-cooks_membrane-a3` (378 DOFs, 4.09 %, 1.25x the automesher's accuracy); best generation-10 agent `g10-cooks_membrane-a7` (710 DOFs, 1.07 %, 4.76x the automesher's accuracy); true solution. Cook's membrane (plane stress, E = 1, nu = 1/3, unit total shear load; dimensionless stress), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/cooks_membrane.npz`, 68,970 DOFs; a coarser reference solve differs from it by 0.39 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/panels.json`). No run was excluded: every Cook's membrane run's setup gives the same solution as the problem's own setup. Colours: von Mises at the element corner nodes (quadratic elements drawn by their corners, midside values not drawn, as the dashboard does), interpolated linearly across each element, Turbo scale clipped to the 1st-99th percentile of the reference (as in the agent dashboard), identical on every panel. Sources: `ace/field_refs/cooks_membrane_auto.json`, `ace_runs/deep1/gen0/runs/g0-cooks_membrane-a3.json`, `ace_runs/deep1/gen10/runs/g10-cooks_membrane-a7.json`.

Caveats: the generation-0 panel is the BEST of the 4 correctly set-up generation-0 runs (by score), not the median; their field errors were 4.09 %-5.38 %. The trained agent uses 2.1x the automesher's DOFs (still tiny); the score charges for that (efficiency term).

Zoom: each panel's box magnifies the clamped top-left corner (0, 44), where the stress peaks (x 0-10, y 37-47.5; black box on the part). Same colour scale. The automesher's few large elements there smear the peak out; the one-shot agent asked for size 2 at that corner and gets part of it; the trained agent asked for size 0.55 there (and at the loaded top-right corner) and matches the true solution.
