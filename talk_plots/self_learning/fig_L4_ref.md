# NAFEMS LE11 (axisymmetric), panel 4: the true solution

The fine reference solve (`ace/field_refs/nafems_le11_axisym.npz`, 53,412 DOFs) drawn on the dashboard's target tessellation (`ace/field_refs/nafems_le11_axisym_target.msh`, inverse-distance mean of the 4 nearest reference points, as `ace/agent_dashboard.py target_structure`). No mesh edges: this is the truth, not a mesh anyone submitted. Same Turbo scale as panels 1-3. NAFEMS LE11 axisymmetric (hollow cylinder / taper / sphere, steel, E = 210 GPa, nu = 0.3, alpha = 2.3e-4 /degC, temperature T = r + z, i.e. x + y in the section; no mechanical load; stresses in MPa), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/nafems_le11_axisym.npz`, 53,412 DOFs; a coarser reference solve differs from it by 0.16 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/nafems_le11_axisym/panels.json`). Excluded: g0-nafems_le11_axisym-a0, g0-nafems_le11_axisym-a4, g0-nafems_le11_axisym-a5, g0-nafems_le11_axisym-a7 (generation 0), because they applied the temperature sqrt(x**2+y**2)+y instead of the problem's x + y, a setup mistake rather than meshing (field error 26.78 %-26.80 %).
