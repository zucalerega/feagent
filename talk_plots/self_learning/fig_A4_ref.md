# Cook's membrane, panel 4: the true solution

The fine reference solve (`ace/field_refs/cooks_membrane.npz`, 68,970 DOFs) drawn on the dashboard's target tessellation (`ace/field_refs/cooks_membrane_target.msh`, inverse-distance mean of the 4 nearest reference points, as `ace/agent_dashboard.py target_structure`). No mesh edges: this is the truth, not a mesh anyone submitted. Same Turbo scale as panels 1-3. Cook's membrane (plane stress, E = 1, nu = 1/3, unit total shear load; dimensionless stress), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/cooks_membrane.npz`, 68,970 DOFs; a coarser reference solve differs from it by 0.39 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/panels.json`). No run was excluded: every Cook's membrane run's setup gives the same solution as the problem's own setup.
