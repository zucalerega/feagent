# NAFEMS LE11 axisymmetric: score vs generations trained

Metric: the scorer's base score (accuracy x efficiency, no bonuses; `checks.base_score` in `ace_runs/deep1/gen*/runs/*nafems_le11_axisym*.json`) divided by the automesher's own score 0.25, so 1x = the automesher (dashed). Best agent per generation (pink), mean of the agents per generation (blue), min-max band. Only correctly set-up runs are used (40 of 44): a run counts when its recorded setup, re-solved on its own mesh, gives the same field error (to 1e-6) as the problem's own setup (`ace/checks.py reference_setup`), so the differences shown are the mesh alone (`data/runs_deep1.csv`, column setup_ok). Excluded: g0-nafems_le11_axisym-a0, g0-nafems_le11_axisym-a4, g0-nafems_le11_axisym-a5, g0-nafems_le11_axisym-a7 (generation 0), because they applied the temperature sqrt(x**2+y**2)+y instead of the problem's x + y, a setup mistake rather than meshing (field error 26.78 %-26.80 %). Generation 0 therefore has no correctly set-up run and is left out. Generation 1: best 2.83x, mean 2.71x (4 runs); generation 10: best 3.52x, mean 3.38x. Circled: the two runs drawn in the panels (`g1-nafems_le11_axisym-a3`, `g10-nafems_le11_axisym-a4`). From generation 1 to 10 the mean field error went from 0.82 % to 0.71 % and the mean DOFs from 748 to 674: a little more accurate with fewer DOFs. Every generation-10 run asks for smaller elements at the two kinks and a coarser background than every generation-1 run, plus a few moderate refinements elsewhere (requests: `data/runs_deep1.csv` -> run files; circled runs: `data/nafems_le11_axisym/panels.json`). Values: `data/per_generation_nafems_le11_axisym.csv`.

Caveats: one training run (no repeats); 4 runs per generation; agents are reassigned between the two problems each generation.
