# Cook's membrane: error maps

Per element: RMS over the reference integration points inside it (12849 points in all) of the relative von Mises error |vm - vm_ref| / max(vm_ref, 0.2 median(vm_ref)) (the run report's pointwise error, ace/run_report.py _field). Log colour scale clipped to 0.003-0.3, identical on the three panels; mesh edges overlaid. Same meshes and numbers as the combined figure. Cook's membrane (plane stress, E = 1, nu = 1/3, unit total shear load; dimensionless stress), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/cooks_membrane.npz`, 68,970 DOFs; a coarser reference solve differs from it by 0.39 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/panels.json`). No run was excluded: every Cook's membrane run's setup gives the same solution as the problem's own setup.
