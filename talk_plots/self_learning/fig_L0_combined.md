# NAFEMS LE11 (axisymmetric): four solutions on one colour scale

Left to right: gmsh automesher (332 DOFs, field error 2.44 %); best generation-1 agent `g1-nafems_le11_axisym-a3` (812 DOFs, 0.71 %, 3.46x the automesher's accuracy); best generation-10 agent `g10-nafems_le11_axisym-a4` (648 DOFs, 0.71 %, 3.44x the automesher's accuracy); true solution. NAFEMS LE11 axisymmetric (hollow cylinder / taper / sphere, steel, E = 210 GPa, nu = 0.3, alpha = 2.3e-4 /degC, temperature T = r + z, i.e. x + y in the section; no mechanical load; stresses in MPa), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/nafems_le11_axisym.npz`, 53,412 DOFs; a coarser reference solve differs from it by 0.16 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/nafems_le11_axisym/panels.json`). Excluded: g0-nafems_le11_axisym-a0, g0-nafems_le11_axisym-a4, g0-nafems_le11_axisym-a5, g0-nafems_le11_axisym-a7 (generation 0), because they applied the temperature sqrt(x**2+y**2)+y instead of the problem's x + y, a setup mistake rather than meshing (field error 26.78 %-26.80 %). Colours: von Mises at the element corner nodes (quadratic elements drawn by their corners, midside values not drawn, as the dashboard does), interpolated linearly across each element, Turbo scale clipped to the 1st-99th percentile of the reference (as in the agent dashboard), identical on every panel. Sources: `ace/field_refs/nafems_le11_axisym_auto.json`, `ace_runs/deep1/gen1/runs/g1-nafems_le11_axisym-a3.json`, `ace_runs/deep1/gen10/runs/g10-nafems_le11_axisym-a4.json`.

Caveats: the generation-1 panel is the BEST of the 4 correctly set-up generation-1 runs (by score), not the median; their field errors were 0.71 %-1.09 %. The trained agent uses 2.0x the automesher's DOFs (still tiny); the score charges for that (efficiency term).

Zoom: each panel's box magnifies the kink G = (1.0, 1.39) where the taper meets the upper cylinder (x 0.9-1.1, y 1.27-1.51; black box on the part). Same colour scale. The automesher's few large elements there blur the peak. The early agent asked for size 0.03 at G on a background of 0.13; the trained agent for 0.016 at G (and 0.021 at the lower kink D, vs 0.04) on a coarser background of 0.2, plus 3 moderate refinements elsewhere (sizes 0.05-0.1). Both resolve the peak like the true solution; the solved fields of panels 2 and 3 look alike (field error 0.71 % vs 0.71 %). What changed is the mesh: smaller elements at the kinks, a coarser background, 648 instead of 812 DOFs (the error maps show where the error moved). Requests: `data/nafems_le11_axisym/panels.json`.
