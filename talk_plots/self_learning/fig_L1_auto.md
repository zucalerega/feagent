# NAFEMS LE11 (axisymmetric), panel 1: gmsh automesher

gmsh with default sizes, quadratic triangles, the problem's correct setup (ace/field_error.py automesher). 332 DOFs, 69 elements, field error 2.44 % (stored: `ace/field_refs/nafems_le11_axisym_auto.json`, 2.44 %). NAFEMS LE11 axisymmetric (hollow cylinder / taper / sphere, steel, E = 210 GPa, nu = 0.3, alpha = 2.3e-4 /degC, temperature T = r + z, i.e. x + y in the section; no mechanical load; stresses in MPa), run `ace_runs/deep1`. Field error = relative energy-norm error of the whole stress field vs the fine reference (`ace/field_refs/nafems_le11_axisym.npz`, 53,412 DOFs; a coarser reference solve differs from it by 0.16 %, so the reference's own error is below that). Each mesh was rebuilt from its request and re-solved with the fixed skfem solver as the scorer does; the re-solved field errors and DOFs match the stored ones (`data/nafems_le11_axisym/panels.json`). Excluded: g0-nafems_le11_axisym-a0, g0-nafems_le11_axisym-a4, g0-nafems_le11_axisym-a5, g0-nafems_le11_axisym-a7 (generation 0), because they applied the temperature sqrt(x**2+y**2)+y instead of the problem's x + y, a setup mistake rather than meshing (field error 26.78 %-26.80 %). Colours: von Mises at the element corner nodes (quadratic elements drawn by their corners, midside values not drawn, as the dashboard does), interpolated linearly across each element, Turbo scale clipped to the 1st-99th percentile of the reference (as in the agent dashboard), identical on every panel.
